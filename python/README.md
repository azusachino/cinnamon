# Python BCC Prototyping Scripts

This directory preserves Python-based BCC (BPF Compiler Collection) scripts for rapid prototyping and historical comparison with Cinnamon's modern Go (`cilium/ebpf` + `bpf2go`) architecture.

## Why Go + cilium/ebpf vs Python BCC?

| Dimension | Python BCC | Go + cilium/ebpf (Cinnamon Core) |
| :--- | :--- | :--- |
| **Compilation** | JIT-compiled at runtime via LLVM in kernel | Ahead-of-Time (AOT) compiled via `clang` + `bpf2go` |
| **Dependencies** | Requires `python3-bcc`, `clang`, kernel headers on target | Single static binary; eBPF bytecode embedded in Go binary |
| **Startup Overhead** | High (seconds to compile BPF C string in memory) | Instantaneous (<10ms load and verify) |
| **Type Safety** | Untyped strings and ctypes structs | Strongly typed Go struct bindings generated by `bpf2go` |
| **Memory Buffer** | `bpf_trace_printk` / perf buffer | High-throughput Linux `BPF_MAP_TYPE_RINGBUF` |

## Running BCC Scripts

Requires Python BCC installed on your Linux distribution (`sudo apt install python3-bcc`):

```bash
sudo uv run python/bcc_execve.py
```
